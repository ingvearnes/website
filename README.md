# CV website

A minimal, luxury real estate inspired CV website built with React and Vite.

## Get started

```sh
npm install
npm run dev
```

Open the local address printed by Vite.

## Make it yours

- Edit the sample `profile`, `expertise`, `experience`, and `education` content near the top of `src/App.jsx`.
- Update the page title and description in `index.html`.
- Replace `src/assets/architecture-hero.png` with an image that suits you, and update its alt text in `src/App.jsx`.
- The sample contact address uses `example.com`; replace it before publishing.

Run `npm run build` to create the production site in `dist/`.
